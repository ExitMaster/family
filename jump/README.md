# 제트팩 점프 (Jetpack Jump)

| 파일 | 주소 | 내용 |
|---|---|---|
| `index.html` | `/jump/` | **온라인 버전** — 각자 자기 기기에서 방 코드로 모여 같이 달리기 |
| `local.html` | `/jump/local.html` | **한 기기 버전** — 한 화면·한 키보드에서 최대 7명 |

## 조작

- 점프: `SPACE` / `↑` / `W`, 또는 화면 터치·클릭
- **길게 누르면 더 높이** 뜨고, 짧게 떼면 살짝만 뛴다
- **공중에서 한 번 더 누르면 제트팩 부스터** — 지금은 연료 **무제한(🔥 ∞)** 이라
  계속 두드리면 계속 올라간다 (`UNLIMITED = false`로 두면 비행당 3번)
- 전체화면: `F` 또는 ⛶ 버튼 · 소리: `S` 또는 🔊 버튼
- 온라인: 닉네임 + **같은 방 코드**(예: `FAM1`) 입력 → 아무나 **Start race** → 3·2·1·GO

## 점수와 별

| 행동 | 결과 |
|---|---|
| 상자를 안전하게 지나감 | +1점 |
| 떠 있는 **별에 몸이 닿음** | ⭐+3 (착지 안 해도 스치기만 하면 됨) |
| **거대 탑**(빨간 깃발) 꼭대기 별 | ⭐+12 |
| 상자 **옆구리**에 부딪힘 | ♥ 하나 잃고 상자 위로 튕겨 오름 |

누구나 **♥ 3개**로 시작합니다. 옆구리를 박으면 하트가 하나 줄고 1.4초 동안
깜빡이며 무적이 됩니다. 3개를 다 잃으면 유령이 되어 둥실 떠오르고, 나머지
사람들은 계속 달립니다. 내려오다 상자 위에 닿는 건 좀 삐뚤어도 **착지**로
쳐주고, 제대로 옆구리를 박은 것만 아픕니다.

거대 탑은 보통 상자 `TOWER_EVERY`(9)개마다 한 번 나오고, 앞에 평소보다
1.9배 긴 활주로가 붙습니다.

별과 산 아이템은 **닉네임 기준으로 저장**되어 어느 기기에서든 이어집니다.
입은 옷은 같은 방 친구들 화면에도 그대로 보입니다.

## 버전이 섞이면

물리 계산이 바뀌면 옛 버전과 새 버전이 서로 다른 경주를 하게 됩니다. 각자
`GAME_VERSION`을 함께 보내므로, 로비에 다른 버전이 섞이면 경고가 뜹니다.
게임 상수(`JUMP_POWER`, `GRAVITY`, `SPEED0`, `ACCEL`, `MAX_AIR`, `TOWER_EVERY`,
`LIVES_MAX` 등)를 바꾸면 `GAME_VERSION`도 함께 올려야 합니다.
현재 버전은 **3**입니다.

## 배포

이 저장소는 **GitHub Pages**로 배포됩니다 (`main` 브랜치 / 루트).
빌드 없는 정적 HTML이라 `main`에 머지되면 1~2분 뒤 자동 반영됩니다.

- 온라인 버전: <https://exitmaster.github.io/family/jump/>
- 한 기기 버전: <https://exitmaster.github.io/family/jump/local.html>

게임 페이지는 `exitmaster.github.io`에서 열리고 데이터는 `Unimai Game Hub`
프로젝트에 있습니다. 서로 다른 도메인이므로, 로그인 오류가 나지 않도록

> ```

## Firebase (온라인 버전 전용)

프로젝트: **Unimai Game Hub** (Spark 무료 요금제)

- **Realtime Database** — 싱가포르(`asia-southeast1`)
- **Authentication** — 익명(Anonymous) 로그인 사용
- 규칙(Realtime Database → 규칙):

```json
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": "auth != null",
        ".write": "auth != null",
        ".validate": "$room.matches(/^[A-Z0-9]{3,6}$/)"
      }
    },
    "banks": {
      "$who": {
        ".read": "auth != null",
        ".write": "auth != null",
        ".validate": "$who.matches(/^[a-z0-9_-]{1,14}$/)"
      }
    }
  }
}
```

`rooms`는 경기 중에만 쓰는 임시 공간(탭을 닫으면 자동 삭제), `banks`는 별과
아바타가 남는 영구 공간입니다. 저금통 열쇠는 **닉네임**이라 어느 기기에서
접속하든 같은 별이 나옵니다. 뒤집어 말하면 같은 닉네임을 입력한 사람은 그 별을
쓸 수 있으니, 가족·친구끼리만 쓰는 방으로 유지해 주세요.

`index.html` 안의 `firebaseConfig` 값은 **비밀번호가 아닙니다.** 웹 앱에 공개적으로 포함되도록 설계된 식별자라 저장소가 public이어도 안전합니다. 실제 접근 제어는 위 규칙이 담당합니다.

## 작동 방식

```
   내 기기                  Firebase                친구 기기
  ┌──────────┐          ┌────────────┐          ┌──────────┐
  │ 내 캐릭터 │──내 높이─▶│ rooms/FAM1 │─친구 높이─▶│ 내 캐릭터 │
  │  (즉시)  │◀─친구 높이─│  players/  │◀─내 높이──│  (즉시)  │
  └──────────┘          └────────────┘          └──────────┘
        └───────── 같은 seed → 똑같은 장애물 배치 ─────────┘
```

내 캐릭터는 내 기기에서 직접 계산해서 점프가 안 밀립니다. 인터넷으로 오가는 건
높이·점수·별·하트뿐(초당 약 12회). 상자와 거대 탑은 방장이 뽑은 `seed` 하나로
각 기기가 알아서 똑같이 만들어 냅니다 — 코스 자체는 네트워크로 보내지 않습니다.

## 문제가 생기면

**빨간 오류 상자가 뜬다** — 순서대로 확인:
1. 승인된 도메인에 `exitmaster.github.io`가 들어 있는지 (위 "배포" 항목)
2. Authentication → Sign-in method → 익명(Anonymous)이 켜져 있는지
3. Realtime Database가 만들어져 있고 규칙이 게시되었는지
4. 인터넷 연결

**사람마다 장애물이 다르게 보인다** — 누군가 옛날 버전을 열고 있는 것. 새로고침하면 해결. `JUMP_POWER` · `GRAVITY` · `SPEED0` · `ACCEL` 값은 모두가 같아야 합니다.

**로비에 유령 플레이어가 남아 있다** — 탭이 비정상 종료된 경우로 보통 저절로 사라집니다. 안 없어지면 Firebase 콘솔 `rooms/{방코드}/players`에서 삭제.

**경주 중에 들어온 사람** — 이번 판은 구경하고 다음 판부터 참여.

## 안전

- 닉네임만 사용. 실명·학교·주소 금지. 방 안의 모두에게 보입니다.
- 방 코드를 아는 사람은 누구나 들어올 수 있으니 공개된 곳에 올리지 마세요.
- 규칙이 쓰기를 `rooms/{코드}` 아래로만 제한하지만, 그 안에서는 로그인한 누구나 쓸 수 있습니다. 가족 게임 용도로는 충분하며, 중요한 데이터를 두는 용도로는 적합하지 않습니다.
