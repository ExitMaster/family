# 깡총데굴 (Hop & Roll)

한 벌짜리 **토끼옷을 입은 아이**가 **꼬당 넘어지고, 데굴데굴 공중제비 돌고, 깡총 뛰고, 고리를 잡고 빙빙 돌다 휙 날아가는**
흐물흐물 물리 플랫폼 게임. 당근을 모으면서 깃발까지 가면 됩니다. 빌드 없는 HTML 파일 하나, 서버·Firebase 필요 없음.

> <https://exitmaster.github.io/family/hoproll/>

## 조작

| | 1P | 2P | 휴대폰·태블릿 |
|---|---|---|---|
| 굴러가기 | `A` `D` | `←` `→` | ◀ ▶ 버튼 |
| 점프 | `W` | `↑` | 점프 버튼 |
| 잡기 (꾹 누르고 있기) | `S` | `↓` | 잡기 버튼 |
| 멈춤 | `Esc` / `P` | | ⏸ |

- **1명**일 때는 `WASD`, 방향키, `스페이스`(점프), `Shift`(잡기) 아무거나 됩니다.
- **2명**은 한 기기에서 같이 합니다. 키보드 하나를 나눠 쓰거나, 휴대폰을 가로로 놓고 왼쪽·오른쪽 버튼을 하나씩.
- 게임패드도 됩니다 (패드 1개 → 1P, 2개 → 1P·2P). 스틱/십자키로 구르고 A 점프, B·X·어깨 버튼 잡기.

## 놀이 방법

- **구르기**: 키가 큰 콩 모양 몸이 앞으로 넘어지고 공중제비를 돌면서 움직입니다. 손을 떼면 오뚝이처럼 다시 일어서요.
- **점프**: 땅이든 벽이든 친구 머리든 몸이 닿아 있으면 뛸 수 있습니다. 몸이 기울어진 쪽으로 조금 휘어서 뜁니다.
- **공중에서**: ◀ ▶ 로 빙글빙글 돌면서 살짝 방향을 바꿀 수 있어요.
- **고리**: 잡기를 꾹 누른 채 고리에 닿으면 매달립니다. ◀ ▶ 로 빙빙 돌리다가 **잡기를 놓으면** 누르고 있는 쪽 위로 휙 날아갑니다.
  점프를 누르면 더 높이 날아가요. 날아가면서 다시 잡기를 누르고 있으면 다음 고리를 잡습니다.
- **친구 잡기 (2명)**: 친구 옆에서 잡기 → 손을 잡고 끌거나, 흔들다 놓아서 던질 수 있습니다. 고리에 매달린 친구에게 매달려 둘이 같이 흔들기도 돼요.
- **통통 발판(분홍)**: 밟으면 아주 높이 튀어 오릅니다.
- **물**: 빠지면 마지막으로 지나간 **깃발(체크포인트)** 에서 다시 시작. 목숨 제한은 없어요.
- 둘이 너무 멀어지면 뒤처진 토끼가 앞 토끼 옆으로 순간이동합니다.
- 한 명이라도 **도착 깃발**에 닿으면 레벨 클리어.

## 별

| | |
|---|---|
| ★ | 도착 |
| ★★ | 당근 60% 이상 |
| ★★★ | 당근 전부 |

2명일 때 당근은 둘이 모은 걸 합쳐서 셉니다. 결과 화면에서 누가 더 많이 모았는지도 보여줘요.
최고 별·최고 시간은 이 기기의 브라우저에 저장됩니다 (`localStorage` `hoproll-v1`).

## 레벨

1. **들판 산책** — 구르기·점프·고리 연습
2. **통통 절벽** — 통통 발판으로 절벽 오르기, 내리막 질주
3. **고리 연못** — 연못 위 고리 8개를 이어서 건너기
4. **흔들 발판** — 움직이는 발판, 높은 발판, 고리 내려오기

## 만든 방식 (고칠 사람용)

- 물리는 직접 짠 간단한 것: 토끼 = 몸 축 위에 원 3개(머리·배·엉덩이)를 붙인 회전하는 강체(키 60, 폭 30),
  땅 = 다각형의 선분들. 120Hz 고정 스텝. 닿은 곳마다 충격량과 마찰을 회전까지 계산해서, 넘어지고 공중제비 도는 힘이 이동으로 바뀝니다.
- 고리·친구 잡기는 손(어깨 사이)에서 잡은 곳까지 늘어나지 않는 줄로 처리합니다. 손이 머리 쪽에 있어서 매달리면 몸이 축 늘어져요.
- 귀와 팔은 verlet 줄이라 흔들흔들합니다. 모양만 담당하고 충돌은 없어요.
- 레벨은 `LEVELS` 배열에 좌표로 적혀 있습니다. `G`(땅 윗면 점들), `P`(사각 발판, `"pad"`=통통 발판, `mover`=움직이는 발판), `Wt`(물), `rings`, `checks`, `carrots`, `signs`.
- 숫자 조정은 스크립트 맨 위 "설정"에서 (`JUMP_V` 점프 힘, `GRAB_REACH_RING` 고리 잡는 거리 등).
- 검증용으로 `window.__hop`에 상태와 `step(n, inputs)`(물리를 직접 n걸음 돌리기)를 노출합니다. 게임 동작에는 영향 없음.
