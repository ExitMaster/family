# eli5

Explain any topic like I'm 5.

```
/eli5 how does DNS work
```

Produces a HTML artifact with big pictures and very few words that explains the
topic to someone who knows nothing about it.

## Source

Vendored from the `eli5` plugin in
[anthropics/claude-plugins-community](https://github.com/anthropics/claude-plugins-community/tree/main/eli5)
(v1.0.0, author: Thariq Shihipar, MIT licensed).

To install it globally instead of per-repo:

```
claude plugin marketplace add anthropics/claude-plugins-community
claude plugin install eli5@claude-community
```
