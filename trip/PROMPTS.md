# 🤖 다른 AI에게 여행 DB 만들게 하기 — 프롬프트 루틴

새 여행지의 카드 데이터를 ChatGPT·Gemini 같은 다른 AI에게 조사·정리시키는 순서입니다.
**① 형식 가르치기 → ② 여행지 시키기 → ③ 보강 → ④ 스스로 검증** 순으로 씁니다.

아래 회색 칸을 **그대로 복사**해서 붙여넣으세요. `《 》` 안만 바꾸면 됩니다.

> 여기 쓰인 16열 형식은 실제로 앱에 넣어 **모든 칸이 제대로 들어가는 것을 확인한** 형식입니다.
> 앱은 열을 **이름으로** 찾기 때문에, 늘 비어 있는 칸(지도링크·카드ID 등)은 아예 뺐습니다.

## ① 형식 가르치기 — 새 대화를 열고 맨 처음

```
너는 우리 가족 여행 플래너 앱에 넣을 여행 데이터를 만들어 줄 거야.
먼저 형식을 알려줄 테니, 이번 답변에서는 데이터를 만들지 말고 이해했는지만 답해 줘.

# 출력 형식
CSV 한 덩어리를 코드블록 하나에 담아서 출력한다. 설명은 코드블록 밖에 쓴다.

맨 위 3줄은 여행 정보(2칸짜리 줄):
여행 이름,《여행 이름》
가는 날,YYYY-MM-DD
오는 날,YYYY-MM-DD

그 다음 줄은 반드시 이 머리글 그대로 — 16칸:
이름,종류,시간(분),가격,설명,위도,경도,할일메모,체크인,체크아웃,출발시각,도착시각,도착위도,도착경도,예약시각,사이트

그 아래로 카드를 한 줄에 하나씩 쓴다.

# ★ 가장 중요한 규칙
**모든 줄은 쉼표가 정확히 15개다** (칸 16개). 안 쓰는 칸도 반드시 빈칸으로 남겨서
자리를 맞춰라. 값 안에 쉼표가 들어가면 그 칸만 큰따옴표로 감싼다.
아래 예시 3줄의 쉼표 자리를 그대로 따라 하면 된다.

체험·먹기·쇼핑 (체크인~도착경도 6칸을 비움):
팀랩 플래닛,체험,120,₩₩₩,"맨발로 물속을 걷는, 빛의 미술관",35.649300,139.789100,갈아입을 양말,,,,,,,14:00,https://www.teamlab.art/

숙소 (시간·가격 비우고, 체크인/체크아웃만 채움):
난바 호텔,숙소,,,짐 놓고 쉬는 우리 집,34.665900,135.501300,여권은 금고에,16:00,10:00,,,,,,

교통 (시간 비우고, 출발/도착시각과 도착좌표를 채움):
간사이공항 특급 라피트,교통,,₩₩,간사이공항→난바 · 특급 지정석,34.434200,135.232900,표 미리 받기,,,10:30,11:15,34.665900,135.501300,,

# 칸별 규칙
- 이름: 짧고 분명하게. 지점이 여럿인 가게는 지점명까지 (예: 이치란 라멘 도톤보리점)
- 종류: 체험 / 먹기 / 쇼핑 / 교통 / 숙소  ← 이 다섯 중 하나만
- 시간(분): 머무는 시간(이동 시간 제외). 숙소·교통은 비운다.
- 가격: ₩ / ₩₩ / ₩₩₩ / 무료
- 설명: 초등학생이 읽고 "가고 싶다"고 느낄 한 줄, 25자 안팎. 구체적으로.
- 위도, 경도: 소수 6자리. **필수** — 비면 앱이 그 줄을 버린다.
- 할일메모: 챙길 것. 여러 개면 세미콜론(;)으로 구분.
- 체크인, 체크아웃: **숙소만**
- 출발시각, 도착시각, 도착위도, 도착경도: **교통만**
- 예약시각: 예약·공연처럼 시각이 정해진 체험·먹기·쇼핑만
- 사이트: 공식 홈페이지. https:// 로 시작. 확실하지 않으면 비운다.

# 꼭 지킬 것
- 좌표와 홈페이지 주소를 **지어내지 마라.** 확실하지 않으면 비우고,
  코드블록 아래에 "확인 필요: OO"로 따로 적어라.
- 종류를 골고루: 체험 위주로 하되 **점심·저녁용 먹기 카드를 하루 2개꼴로**,
  숙소와 공항↔시내 교통도 반드시 포함.
- 소요 시간은 실제 방문 후기 기준으로 현실적으로.
- 아이들이 쓰는 앱이다. 술집 등 성인 대상 장소는 넣지 마라.

이해했으면 "준비됐어요"라고만 답해 줘.
```

## ② 여행지 데이터 만들기

```
《오사카》 여행 데이터를 만들어 줘.

- 여행 이름: 《오사카 2027》
- 날짜: 《2027-05-01》 ~ 《2027-05-04》
- 가는 사람: 어른 2명, 초등학생 2명 (《10살, 8살》)
- 아이들이 좋아하는 것: 《놀이공원, 동물, 캐릭터 굿즈》
- 어른이 챙기고 싶은 것: 《유명한 먹거리 한 곳 이상, 너무 빡세지 않게》
- 숙소 위치 희망: 《난바 근처》
- 카드 개수: 《18》장쯤 (체험 8, 먹기 6, 쇼핑 2, 숙소 1, 교통 1)

앞에서 알려준 CSV 형식 그대로, 코드블록 하나로 출력해 줘.
줄마다 쉼표가 15개인지 세어 보고 출력해.
```

## ④ 스스로 검증시키기 — 앱에 넣기 직전에 한 번

```
지금 만든 CSV를 네가 점검해 줘. 고칠 게 있으면 고쳐서 전체를 다시 출력하고,
아래를 표로 정리해 줘.

1. 머리글이 16칸, 글자 그대로인가
2. **쉼표가 15개가 아닌 줄**이 있는가 (있으면 그 줄 이름과 실제 개수)
3. 위도·경도가 빈 줄이 있는가
4. 좌표가 《오사카》 범위를 벗어난 줄이 있는가
5. 종류가 다섯 가지(체험/먹기/쇼핑/교통/숙소) 밖인 줄
6. 숙소가 아닌데 체크인/체크아웃이 찼거나, 교통이 아닌데 출발/도착시각이 찬 줄
7. 네가 확신하지 못하는 좌표·홈페이지 주소 목록
```

## 받은 데이터를 앱에 넣기

**방법 A — 앱에 바로 붙여넣기 (빠름)**
코드블록의 CSV를 복사 → 앱 홈 **📋 표에서 가져오기** → 붙여넣고 **붙여넣기로**.
CSV든 시트에서 복사한 탭 표든 앱이 알아서 알아봅니다.

**방법 B — 시트를 거쳐서 (원본까지 관리, 권장)**
1. CSV를 메모장에 붙여넣고 `오사카.csv`로 저장
2. 구글 시트 → **파일 → 가져오기 → 업로드** → 새 시트로
3. 그 시트를 **파일 → 공유 → 웹에 게시**(CSV) → 주소 복사
4. 앱 **📋 표에서 가져오기** → "☁️ 구글 시트 주소"에 붙여넣고 **☁️ 주소에서**

이후 시트를 고칠 때마다 앱에서 **🔄** 만 누르면 됩니다.

## 넣은 뒤 어른이 볼 것

AI가 만든 데이터는 **좌표와 홈페이지 주소가 틀릴 수 있습니다.**

- **지도**를 보면 좌표가 엉뚱한 카드가 바로 눈에 띕니다 (딴 동네에 찍힘).
- 🔗 링크를 눌러 실제로 열리는지 확인 — 안 열리면 카드 편집(✏️)에서 지우거나 고치세요.
- 위도·경도가 빈 줄은 앱이 건너뛰고 "몇 줄 건너뛰었다"고 알려 줍니다.
  그 카드는 앱의 **🔍 장소 검색**으로 직접 찾아 넣는 편이 정확합니다.
- 같은 이름의 여행을 다시 가져오면 **덮어쓰기가 아니라 갱신**이고,
  아이들이 짜 둔 일정은 그대로 남습니다.
