# 한글마켓

20명 안팎의 지인이 한 번의 플리마켓을 준비하며 상품을 미리 올리고 예약하는 모바일 웹앱입니다.

## 접속

정적 웹 서버로 저장소 루트를 연 뒤 아래 초대 주소로 접속합니다.

```text
/market/?invite=hangul-market
```

프로필은 브라우저에 저장되며 Firebase 익명 인증 UID로 상품 소유자와 예약자를 구분합니다. 상품과 예약은 Firebase Realtime Database의 `hangulMarket` 경로에서 실시간 공유됩니다.

## 기능

- 닉네임과 연락처로 입장
- 사진 1~5장, 상품명, 가격 또는 무료나눔, 수량, 설명 등록
- 최신 등록순 게시판과 판매자 필터, 기기별 찜
- 상품 상세 페이지 및 공유 링크
- 재고 수량 내 선착순 예약과 본인 예약 취소
- 등록자만 상품 수정, 삭제, 판매 완료 처리

## 배포 전 준비

1. Firebase Authentication에서 **익명 로그인**을 활성화합니다.
2. 배포 도메인을 Firebase Authentication의 **승인된 도메인**에 추가합니다.
3. 저장소 루트의 `firebase-rules.json` 전체를 Realtime Database 규칙에 게시합니다.

Firebase Console의 메뉴별 클릭 순서, 도메인 입력 예시, 게시 후 검증 방법과 문제 해결은
저장소의 **[Firebase Console 배포 준비 가이드](../FIREBASE.md)**를 따라 진행하세요.

개발을 이어받는 경우에는 제품 요구사항, 데이터 모델, 코드 흐름, 알려진 위험과 다음 작업을
정리한 **[개발 인수인계서](HANDOFF.md)**를 먼저 확인하세요.

초대 링크는 소규모 지인 모임을 위한 가벼운 접근 장벽이며 강력한 보안 인증 수단은 아닙니다. 링크를 받은 사람은 다른 사람에게 전달할 수 있습니다.
