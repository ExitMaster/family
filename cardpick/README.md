# 카드픽 (Card Pick)

결제 직전에 가장 유리한 카드와 최대 2장 분할결제 조합을 계산하는 개인용 안드로이드 PWA입니다.

## 포함 기능

- 카드 4장 기본 등록
- 월초 카드별 실적구간 드롭다운
- 삼성 SELECT 서비스 2 옵션 선택
- 롯데 국민행복 통합할인한도 직접 입력
- 결제처·추정 업종·금액·온/오프라인·결제방식 입력
- 단일 카드 최대 할인 추천
- 2장 분할결제 최적화
- 업종 확인, 오프라인 현장결제, 무이자할부 등 경고
- 월 할인한도·횟수 자동 차감
- 신한 교육비 20만원 이상 결제 건수 추적
- 고정 교육비 5건 기본 등록
- Link 혜택 수동 등록·사용완료 표시
- 카드사 앱 잔여한도 수동 보정
- 결제 결과 적용/미적용 확인
- JSON 백업·복원
- 안드로이드 공유 메뉴를 통한 Google Drive 수동 백업
- 오프라인 실행 및 홈 화면 설치

## 로컬 실행

PWA와 서비스 워커는 `file://`에서 작동하지 않으므로 간단한 웹서버가 필요합니다.

```bash
cd card-benefit-pwa
python3 -m http.server 8080
```

같은 기기에서 `http://localhost:8080`을 엽니다.

PC에서 서버를 실행하고 안드로이드에서 접속하려면 같은 Wi-Fi에서 PC의 내부 IP를 사용합니다.

```text
http://192.168.x.x:8080
```

단, 홈 화면 설치와 서비스 워커는 원칙적으로 HTTPS 또는 localhost가 필요합니다. 실제 사용 시 GitHub Pages, Cloudflare Pages, Netlify 등에 정적 배포하는 것이 가장 간단합니다.

## 사용 순서

1. `카드` 탭에서 적용 월과 각 카드의 실적구간을 선택합니다.
2. 롯데 국민행복은 카드사 앱에 표시되는 통합할인한도를 입력합니다.
3. 삼성카드는 현재 사용하는 SELECT 서비스 2 옵션을 선택합니다.
4. `추천` 탭에서 결제 정보를 입력하거나 고정결제를 불러옵니다.
5. 추천대로 결제한 뒤 `결제 기록` 버튼을 눌러 한도에 반영합니다.
6. 월 2~3회 카드사 앱과 비교해 `카드사 값으로 보정`합니다.
7. `기록` 탭에서 Google Drive로 수동 백업합니다.

## 데이터 저장과 보안

- 카드번호, 계좌정보, 카드사 로그인정보를 저장하지 않습니다.
- 데이터는 브라우저 `localStorage`에 저장됩니다.
- 브라우저 데이터 삭제 또는 기기 교체에 대비해 JSON 백업을 권장합니다.
- Android의 `Drive로 수동 백업`은 시스템 공유 메뉴를 열며, 사용자가 Google Drive를 선택하는 방식입니다. 별도의 Google OAuth 설정이 필요하지 않습니다.

## 현재 확인이 필요한 카드 규칙

- 신한 Edu Plan+와 신한 Edu의 주요 구간·교육 혜택은 공식 카드 페이지 기준으로 입력했습니다.
- 롯데 국민행복의 학원 10%, 월 1회 최대 1만원은 사용자 확인값을 반영했습니다. 전체 통합할인한도는 카드사 앱 값을 직접 입력하도록 설계했습니다.
- 삼성 iD SELECT ALL은 SELECT 서비스 2의 두 옵션을 지원합니다. 구간별 한도와 기본 다이소 한도는 카드 앱의 `내 카드 혜택`과 대조해 보정하는 것을 권장합니다.
- 카드사 가맹점 업종, 간편결제 승인명, 이벤트 중복 여부에 따라 실제 할인과 차이가 발생할 수 있습니다.

## 파일 구성

- `index.html`: 앱 셸
- `styles.css`: 모바일 UI
- `default-data.js`: 카드·혜택·고정결제 기본 데이터
- `engine.js`: 할인 계산, 분할결제, 한도 차감 엔진
- `app.js`: 화면과 로컬 저장
- `service-worker.js`: 오프라인 캐시
- `manifest.webmanifest`: PWA 설정
