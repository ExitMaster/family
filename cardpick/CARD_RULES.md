# 기본 카드 규칙과 확인 상태

## 신한 Edu Plan+

공식 상품 페이지: https://www.shinhancard.com/pconts/html/card/apply/credit/1228598_2207.html

- 학원비 기본 캐시백
  - 30만~50만원: 3%, 월 1만원
  - 50만~100만원: 5%, 월 2만원
  - 100만~200만원: 7%, 월 5만원
  - 200만원 이상: 10%, 월 9만원
- 승인금액 20만원 이상 학원비 결제 건수
  - 3~4건: 5천원 추가
  - 5건 이상: 1만원 추가
- 오프라인은 일반전문학원·학습지·유치원 업종, 온라인은 학원비 전용 PG 거래가 대상
- 무이자할부, 일부 간편결제·키오스크 승인명 등은 제외될 수 있음
- 이마트 에브리데이·롯데슈퍼 등 기업형 슈퍼마켓은 3대 할인점 혜택 제외

## 신한 Edu

공식 상품 페이지: https://www.shinhancard.com/pconts/html/card/apply/credit/1188281_2207.html

- 교육업종 캐시백
  - 50만~100만원: 5%, 월 1만5천원
  - 100만~150만원: 7%, 월 3만원
  - 150만원 이상: 10%, 월 4만5천원
- 승인금액 20만원 이상 교육비 결제 건수
  - 2건: 3천원
  - 3건: 4천원
  - 4건 이상: 5천원
- 일반전문학원·학습지·유치원 업종이며 학원 방문 결제시에만 적용
- 기업형 슈퍼마켓과 온라인 마트는 생활 캐시백 제외

## 롯데 국민행복

참고 페이지: https://www.card-gorilla.com/card/detail/455

- 사용자 확인값 반영: 학원 10%, 월 1회, 최대 1만원
- 병원·약국 5%, 교통 10%, 통신 정액 할인 등 기본 규칙을 등록
- 여러 혜택이 공유하는 실제 월 통합할인한도는 카드사 앱 값을 월초에 직접 입력
- 상세 업종·결제경로는 보유 카드의 상품설명서 또는 카드 앱으로 확인 필요

## 삼성 iD SELECT ALL

공식 상품 페이지: https://www.samsungcard.com/home/card/cardinfo/PGHPPCCCardCardinfoDetails001?code=AAP1875

- SELECT 서비스 2 옵션을 월초 카드 화면에서 선택
  - 온라인쇼핑·의료·배달앱 7%
  - 음식점·편의점·할인점·주유 7%
- 기본값으로 40만~80만원 7천원, 80만~120만원 1만원, 120만원 이상 1만5천원 한도를 등록
- 다이소 기본혜택은 초기 계산용 규칙이며 실제 카드 앱 한도와 대조 후 보정 권장
- 무이자할부와 삼성카드 할인이 이미 적용된 거래 등은 제외될 수 있음

## 공통 원칙

- 가맹점 업종은 카드사 등록 업종이 기준이므로 앱은 `업종 확인 필요` 경고를 표시합니다.
- Link 혜택은 기본 카드 혜택과 중복된다고 가정하지 않고 별도 알림만 표시합니다.
- 실제 카드사 한도와 차이가 나면 카드 화면의 `카드사 값으로 보정` 기능으로 수정합니다.
