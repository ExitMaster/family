# 🎺 트럼펫 알람시계

**1층에 내려가서 나무 사진을 찍어야만 꺼지는 알람시계.** 침대에 누운 채로는 절대 못 끈다.

주소: <https://exitmaster.github.io/family/alarm/>

| 파일 | 주소 |
|---|---|
| `index.html` | `/alarm/` |

---

## 어떻게 쓰나

1. 알람 시간과 요일을 고른다 (기본: 평일 오전 7시)
2. **⏰ 알람 켜기** 를 누른다 → 대기 화면
3. 태블릿을 **충전기에 꽂고 이 화면을 켜둔 채로** 잔다
4. 아침에 트럼펫 팡파레가 터진다 🎺
5. **미션 시작** → 태블릿을 들고 1층까지 걸어 내려간다 (기본 40걸음)
6. 카메라가 열리면 **나무를 화면에 꽉 차게** 찍는다 → 초록 비율이 통과 기준을 넘으면 알람 끝!

처음 써보기 전에 **🧪 지금 한 번 해보기** 버튼으로 연습해볼 수 있다.

## 미션 검사 방식

서버도 AI도 없이 태블릿 혼자 검사한다.

**1단계 — 진짜 움직였나 (`devicemotion`)**
가속도 센서의 크기 변화가 임계치를 넘으면 한 걸음으로 센다 (연속 감지 방지 260ms 간격).
저역 통과 필터를 걸어서 살짝 흔드는 정도로는 잘 안 세진다.

**2단계 — 진짜 나무인가 (픽셀 검사)**
카메라 화면을 128×96으로 줄여 픽셀마다 검사한다.

```js
if (g > 42 && g > r * 1.14 && g > b * 1.05) green++;   // 초록 픽셀
```

초록 픽셀 비율이 기준(기본 15%)을 넘어야 통과. 실제 색으로 확인한 결과:

| 찍은 것 | 초록 비율 | 결과 |
|---|---|---|
| 흰 천장 / 베이지 벽 / 어두운 방 / 하늘 | 0% | ❌ |
| 화분이 화면 아래 20%만 | 20% | ✅ |
| 풀밭+하늘 반반 | 50% | ✅ |
| 나뭇잎 클로즈업 | 100% | ✅ |

천장·벽·이불을 찍는 꼼수는 막히고, 나무·화분·풀밭은 통과한다.

**움직임 센서를 못 쓰는 기기**(데스크톱 브라우저 등)에서는 4초 뒤 자동으로 사진 단계로 넘어간다.

## 도망가면?

스누즈 버튼은 **없다.** 미션을 성공할 때까지 팡파레가 반복되고, 90초에 걸쳐 소리가 점점 커진다.
게다가 —

- 사진 검사에 **실패**하면 → 볼륨 ×1.35, 화면 흔들림
- 미션 도중에 **다른 앱으로 나가거나 화면을 내리면** → 볼륨 ×1.35, 화면 흔들림 (최대 ×2.2)

## 상으로 받는 것

- **🔥 연속 성공** — 하루라도 빠지면 1로 초기화
- **🏆 레벨** — 성공 1번 = 10 XP, 배지 하나 = 5 XP, 30 XP마다 레벨업
- **🌤️ 기상 카드** — 찍은 나무 사진 + 날짜 + 일어난 시각 + 바깥 온도. 최근 24장 보관
- **🏅 배지 7종** — 첫 성공 🥇 / 3일 연속 🔥 / 일주일 연속 🌟 / 열 번 성공 🏅 / 초록 50% 넘김 🌳 / 새벽 6시 전 🐓 / 2분 안에 성공 ⚡

온도는 위치 권한을 허락하면 [Open-Meteo](https://open-meteo.com/)에서 가져온다. 거절하거나 인터넷이 없으면 `—`로 두고 넘어간다. **온도 때문에 미션이 막히는 일은 없다.**

## 소리

오디오 파일 없이 **Web Audio로 트럼펫 소리를 직접 합성**한다.
톱니파+사각파를 섞고 로우패스 필터를 빠르게 열어 "빵!" 하는 어택을 만들고, 5.4Hz 비브라토를 얹었다.
멜로디는 기병대 돌격 나팔 (`솔–도–미–솔–미–솔`). 성공하면 화이트노이즈로 만든 박수 소리가 나온다.

## 알아둘 것

- **탭이 열려 있어야 울린다.** 이건 웹페이지라서 앱처럼 백그라운드에서 알람을 울릴 수 없다.
  자기 전에 이 화면을 띄워두고, 홈 버튼을 누르거나 다른 탭으로 가면 안 된다.
- **자동 잠금을 꺼두면 확실하다.** Wake Lock API로 화면 꺼짐을 막지만, iPadOS 설정 →
  디스플레이 및 밝기 → 자동 잠금 → **안 함** 으로 해두는 게 안전하다. 충전기도 꼭 꽂을 것.
- **카메라는 `https`에서만 열린다.** 위 GitHub Pages 주소로 열면 된다.
  `file://`로 열면 카메라가 안 켜진다.
- 처음 한 번은 **카메라 허용 / 동작 센서 허용** 팝업이 뜬다. 전부 허용해야 미션을 할 수 있다.
- 기록은 그 태블릿의 브라우저(`localStorage` 키 `alarm-v1`)에만 저장된다. 사진은 320px JPEG로
  줄여서 저장하고 24장까지만 남긴다. Safari 방문 기록/데이터를 지우면 카드도 사라진다.

## 난이도 조절

홈 화면 맨 아래에서 바꿀 수 있다.

- **걸어야 하는 걸음**: 10~200 (기본 40) — 1층이 멀면 늘리고, 너무 힘들면 줄인다
- **사진 초록 비율**: 5~60% (기본 15%) — 겨울에 잎이 없으면 낮추고, 더 빡세게 하려면 올린다

## 만듦새

빌드 없음, 서버 없음, 라이브러리 없음. 단일 HTML 파일 하나에 전부 들어 있다.

```
알람 대기 ──(설정한 시각)──▶ 팡파레 🎺
                                │ 미션 시작
                                ▼
                          걸음 세기 (40걸음)
                                │
                                ▼
                     카메라 + 초록 픽셀 검사 ──실패──▶ 볼륨↑ 다시 찍기
                                │ 통과
                                ▼
                  박수 + 색종이 + 기상 카드 + 배지 🎉
```
