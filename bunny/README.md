# 토끼 점프 (Bunny Jump)

| 파일 | 주소 | 내용 |
|---|---|---|
| `index.html` | `/bunny/` | **온라인 버전** — 각자 자기 기기에서 방 코드로 모여 같이 달리기 (2~6명) |

## 조작

- 점프: `SPACE` / `↑` / `W`, 또는 화면 터치·클릭
- 별명 + **같은 방 코드**(예: `FAM1`) 입력 → 아무나 **경주 시작** → 3·2·1·GO

## 규칙

같은 코스를 동시에 달려서 **점수가 높은 사람이 이깁니다.** 점수는 달린 거리(10픽셀당 1점)와 모은 ⭐(개당 5점)를 더한 값입니다.

- 🌵 선인장 · 🪨 바위 · 🌳 나무 — 뛰어넘기
- 🕳️ 구덩이 — 발이 땅에 닿아 있으면 빠집니다. 반드시 점프해서 건너기
- 🐦 새 — 낮게 날아옵니다. **뛰면 부딪히니 그냥 서서 지나가기**
- ⭐ 별 — 5점. 높이 떠 있는 별은 🚀 없이는 못 닿습니다
- 🚀 로켓 — 5초 동안 점프가 훨씬 높아짐
- ❤️ 목숨 3개 — 부딪히면 1개가 줄고 1.5초 무적. 0이 되면 아웃
- 👻 유령 — 뒤에서 계속 따라옵니다. 부딪힐 때마다 조금씩 가까워지고, 잡히면 목숨이 남아 있어도 즉시 아웃

무실수로 달려도 **40초쯤이면 유령이 따라잡습니다.** 경주가 끝없이 늘어지지 않게 하려는 장치라, 유령은 "시간 제한" 역할입니다.

모두 아웃되면 경주가 끝나고 점수가 비교됩니다.

## 배포

이 저장소는 **GitHub Pages**로 배포됩니다 (`main` 브랜치 / 루트).
빌드 없는 정적 HTML이라 `main`에 머지되면 1~2분 뒤 자동 반영됩니다.

- <https://exitmaster.github.io/family/bunny/>

## Firebase

제트팩 점프(`/jump/`)와 **같은 프로젝트·같은 규칙·같은 설정값**을 그대로 씁니다. 새로 등록하거나 바꿀 것이 없습니다.

프로젝트: **Unimai Game Hub** (Spark 무료 요금제)

- **Realtime Database** — 싱가포르(`asia-southeast1`)
- **Authentication** — 익명(Anonymous) 로그인
- 승인된 도메인에 `exitmaster.github.io`가 이미 등록되어 있습니다
- 규칙도 이미 `rooms/{방코드}` 전체에 걸려 있어 **그대로 두면 됩니다**:

```json
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": "auth != null",
        ".write": "auth != null",
        ".validate": "$room.matches(/^[A-Z0-9]{3,6}$/)"
      }
    }
  }
}
```

> 방 코드는 두 게임이 같은 `rooms/` 아래를 씁니다. 제트팩 점프와 **다른 방 코드**를 쓰세요. 같은 코드를 쓰면 서로의 방에 섞여 들어갑니다.

`index.html` 안의 `firebaseConfig` 값은 **비밀번호가 아닙니다.** 웹 앱에 공개적으로 포함되도록 설계된 식별자라 저장소가 public이어도 안전합니다. 실제 접근 제어는 위 규칙이 담당합니다.

## 작동 방식

```
   내 기기                  Firebase                친구 기기
  ┌──────────┐          ┌────────────┐          ┌──────────┐
  │ 내 토끼   │──내 높이─▶│ rooms/BUN1 │─친구 높이─▶│ 내 토끼   │
  │  (즉시)  │◀─친구 높이─│  players/  │◀─내 높이──│  (즉시)  │
  └──────────┘          └────────────┘          └──────────┘
        └───────── 같은 seed → 똑같은 코스 배치 ─────────┘
```

내 토끼는 내 기기에서 직접 계산해서 점프가 안 밀립니다. 인터넷으로 오가는 건 높이·점수·목숨·유령 위치뿐(초당 약 12회).

원본 게임은 물리를 **프레임 단위**(`vy += 0.7`)로 계산했는데, 기기마다 초당 프레임 수가 달라서 그대로 두면 사람마다 코스가 어긋납니다. 온라인 버전은 전부 **초 단위**(`GRAVITY = 2520`)로 바꿨습니다.

## 문제가 생기면

**빨간 오류 상자가 뜬다** — 순서대로 확인:
1. 승인된 도메인에 `exitmaster.github.io`가 들어 있는지
2. Authentication → Sign-in method → 익명(Anonymous)이 켜져 있는지
3. Realtime Database가 만들어져 있고 규칙이 게시되었는지
4. 인터넷 연결

**사람마다 코스가 다르게 보인다** — 누군가 옛날 버전을 열고 있는 것. 새로고침하면 해결. 스크립트 위쪽 "게임 설정" 값은 모두가 같아야 합니다.

**모르는 사람이 방에 있다** — 제트팩 점프와 같은 방 코드를 썼을 수 있습니다. 다른 코드로 바꾸세요.

**로비에 유령 플레이어가 남아 있다** — 탭이 비정상 종료된 경우로 보통 저절로 사라집니다. 안 없어지면 Firebase 콘솔 `rooms/{방코드}/players`에서 삭제.

**경주 중에 들어온 사람** — 이번 판은 구경하고 다음 판부터 참여.

## 안전

- 별명만 사용. 실명·학교·주소 금지. 방 안의 모두에게 보입니다.
- 방 코드를 아는 사람은 누구나 들어올 수 있으니 공개된 곳에 올리지 마세요.
- 규칙이 쓰기를 `rooms/{코드}` 아래로만 제한하지만, 그 안에서는 로그인한 누구나 쓸 수 있습니다. 가족 게임 용도로는 충분하며, 중요한 데이터를 두는 용도로는 적합하지 않습니다.
